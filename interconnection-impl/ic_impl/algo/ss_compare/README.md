# SS-Compare: 基于秘密分享的安全比较算法

## 概述

SS-Compare 是一个基于秘密分享（Secret Sharing）的多方安全比较算法，支持在不泄露原始数据的情况下，安全地计算多方数据的最小值或最大值。

## 功能特性

- **支持的操作**：
  - `min`: 最小值比较
  - `max`: 最大值比较

- **支持的比较轴**：
  - `axis=-1`: 全局比较（所有数据中的最大值/最小值）
  - `axis=0`: 按行（样本）比较
  - `axis=1`: 按列（特征）比较

- **协议支持**：
  - Semi2K
  - ABY3

## 实现原理

1. **数据编码**：各方将本地数据编码为秘密分享格式
2. **数据拼接**：将各方数据横向拼接形成完整的数据矩阵
3. **安全比较**：在SPU设备上执行安全的最小值/最大值计算
4. **结果输出**：将结果解码并保存到输出文件

## 文件结构

- `ss_compare_context.h/cc`: 算法上下文定义和初始化
- `ss_compare_handler.h/cc`: 算法处理器实现
- `ss_compare.proto`: Protobuf 协议定义
